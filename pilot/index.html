      Как считаем

      балл = 0,5 × траты в сетях + 0,3 × клиенты + 0,2 × мерчи

      • Каждая часть переводится в 0–100: значение гекса делим на 99-й перцентиль по городу. Траты нормируются отдельно для каждой сети, берётся лучшая из трёх.
      • Траты — оборот по картам банка в магазинах сетей за сентябрь 2026. Магазины без трат не учитываются.
      • Зона — сильные гексы (топ-200 в Москве, топ-100 в Питере), между которыми не больше одного гекса, плюс одно кольцо соседних гексов. Цифры зоны посчитаны по всем гексам внутри контура. Порядок зон — по сумме баллов сильных гексов.
      • Клиенты — уникальные клиенты банка в гексе. Один человек попадает в несколько соседних гексов, поэтому по зоне показываем среднее на гекс, а не сумму.
      • Граница города взята из слоя гексов, поэтому в «Москву» входит ближнее Подмосковье, а в «Петербург» — Мурино и Кудрово.
